# USMLE Prompt Engineering

Reproducible prompt-engineering evaluation of LLM performance on USMLE multiple-choice questions. Implements a factorial experiment comparing role assignment, explanation requirements, and zero-, one-, and few-shot prompting. Includes notebooks, prompt templates, model outputs, and performance summaries.

## Repository Contents

- `notebooks/` - Jupyter notebooks and HTML reports
- `data/` - Input datasets and documentation
- `outputs/` - Model predictions and performance summaries
- `prompts/` - Prompt templates used in experiments
